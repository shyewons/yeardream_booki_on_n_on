# 에셋·페이지별 CSS 가이드

페이지별 스타일 작업 시 해당 절과 참고 시안을 함께 전달합니다. 표와 본문의 `backgrounds/...`, `characters/...`, `icons/...` 같은 경로는 이 문서가 있는 **`design/assets/` 기준 상대 경로**입니다. 프로젝트 루트에서 참조할 때는 앞에 `design/assets/`를 붙입니다.

## 폴더별 사용 기준

- `backgrounds/`: 목장 풍경, 공책·동화책 등 화면이나 내용 영역의 바탕으로 사용하는 이미지. 공책 3개는 현재 이 폴더에 있습니다.
- `characters/`: 양·알파카 등 캐릭터 이미지.
- `icons/`: **아이콘에 한정하지 않고, 캐릭터·배경을 제외한 기타 사용 이미지**를 넣는 폴더입니다. 말풍선·선물·장식과 SVG 아이콘을 함께 보관하며 PNG·SVG 등 파일 형식으로 폴더를 나누지 않습니다. 말풍선도 배경색이나 아이콘 크기에 맞추지 않고 해당 화면의 안내 영역 크기로 사용합니다.
- 현재 `textures/`, `illustrations/` 등 다른 폴더에 있는 파일은 아래 표의 실제 경로를 따릅니다. 새로 분리하는 기타 이미지는 `icons/`에 저장합니다.
- `archive/`의 자료는 이전 버전 참고용이며 현재 배포 에셋과 구분합니다. 파일이 이동되면 링크와 본문 경로를 함께 수정합니다.

## 01A 적용 구분 — 별명 입력

참고: [01A-nickname.png](../mockups/farm/01A-nickname.png)

### 에셋과 CSS

| 요소 | 적용 방식 |
| --- | --- |
| 배경 | nickname-meadow.png를 화면 전체 장식 배경으로 사용. 비율을 유지하고 화면에 맞춰 잘라 표시 |
| 줄 두 개 | 구형 시안은 아카이브의 hanging-rope.png를 두 번 배치한 구성. 이름표 기준으로 원본 비율 유지. 현재 assets 폴더에 파일이 있다고 가정하지 않음 |
| 크림색 이름표 | 둥근 사각형, 크림색 배경, 약한 그라데이션, 위쪽 밝은 테두리와 부드러운 바깥 그림자 |
| 줄 구멍 | 작은 원과 안쪽 그림자 |
| 입력란 | 밝은 아이보리 배경, 둥근 모서리, 황갈색 테두리, 약한 안쪽 그림자 |
| 초록 버튼 | 짙은 올리브색 그라데이션, 둥근 모서리, 위쪽 하이라이트, 아래쪽 그림자 |
| 표면 질감 | 이름표와 버튼에 ui-paper-grain.png를 겹쳐 적용. 글자 뒤에서 과도하게 드러나지 않도록 조절 |
| 글자 | 실제 텍스트로 배치. 짙은 갈색 고딕, 버튼은 밝은 글자 |

### 배치

- 이름표 안은 **안내 문구 → 입력란과 ‘의 목장’ → 상태 안내 영역 → 버튼** 순서로 배치합니다. 01A의 상태 안내 영역은 빈 공간입니다.
- 입력란과 버튼은 이름표 내부의 flex 또는 grid 배치로 구성합니다. 배경 그림의 좌표에 고정하지 않습니다.
- 입력란은 늘어날 수 있게 하고, ‘의 목장’은 옆에서 하나의 덩어리로 보이게 합니다.
- 줄·구멍 같은 장식만 이름표를 기준으로 절대 위치를 사용할 수 있습니다.
- 상태 안내가 표시될 공간을 기본 화면에도 확보해 01B~01D로 바뀔 때 버튼이 크게 움직이지 않게 합니다.
- 장식·질감 레이어에는 pointer-events: none을 적용하고 글자·입력란·버튼보다 뒤에 둡니다.

### 반응형·상태 스타일

- 1024×768 CSS px를 기준으로 확인하되 화면 전체를 고정 크기로 만들지 않습니다.
- 모바일에서는 이름표 폭·안쪽 여백·장식을 줄이고 문구의 줄바꿈을 허용합니다. 텍스트를 통째로 축소해 맞추지 않습니다.
- 입력 행은 min-width: 0 등으로 가로 넘침을 방지하고, 긴 안내 문구는 자연스럽게 줄바꿈합니다.
- 높이가 부족하면 이름표 내용에 따라 페이지가 세로로 늘어나고 스크롤될 수 있게 합니다.
- 입력란과 버튼은 초점 테두리를 유지합니다. 눌림 상태는 아래쪽 그림자를 줄이는 방식으로 표현합니다.
- 생성 시안의 미세한 위치 차이보다 공통 컴포넌트의 정렬과 간격을 우선합니다.

## 02 화면 공통 CSS

### 에셋과 CSS

| 요소 | 적용 방식 |
| --- | --- |
| 목장 배경 | farm-meadow.png를 화면 전체 장식 배경으로 사용. 비율 유지, cover로 화면에 맞춤 |
| 이름표 줄 | 구형 시안은 아카이브의 hanging-rope.png 두 개를 사용. 짧은 줄은 원본 비율을 유지한 이미지의 위쪽을 장식 래퍼에서 잘라 표시하고 매듭은 유지 |
| 양·알파카 | sheep.png·alpaca.png. 같은 종류는 동일 에셋 재사용, object-fit: contain |
| 이름표·제목판·카테고리 표식·안내 패널 | 크림색 배경, 둥근 모서리, 얇은 테두리, 위쪽 하이라이트와 부드러운 그림자 |
| 나의 기록 버튼 | 크림색 배경·짙은 갈색 글자·공통 질감 |
| 새 책 만들기·다시 불러오기 버튼 | 올리브색 그라데이션·밝은 글자·공통 질감 |
| 버튼·이름표 질감 | ui-paper-grain.png를 일정한 크기로 반복. 장식 레이어는 pointer-events: none |
| 기록·더하기·화살표 아이콘 | 공통 SVG를 inline SVG 또는 CSS mask로 적용하여 글자색에 맞춤. 스트로크까지 포함한 viewBox 사용 |
| 페이지 점·화살표 원형 바탕 | CSS 원형·테두리·배경색·그림자. 별도 PNG 없음 |

### 상단과 반응형

- 태블릿에서는 왼쪽에 ‘[별명]의 목장’ 이름표, 오른쪽에 ‘나의 기록’과 ‘새 책 만들기’를 나란히 배치합니다.
- 오른쪽 두 버튼은 grid-template-columns: repeat(2, minmax(0, 1fr)) 등으로 같은 폭·높이를 유지합니다. 문구 길이에 따라 한쪽만 커지지 않게 합니다.
- 이름표의 별명이 길어지면 줄바꿈과 높이 증가를 허용합니다. 이름표와 오른쪽 버튼이 겹치지 않게 합니다.
- 모바일에서는 이름표를 윗줄에 두고, 같은 크기의 버튼 두 개를 아랫줄에 나란히 배치합니다.
- 1024×768 CSS px를 기본 확인 크기로 삼되 전체 화면을 고정 배율로 축소하지 않습니다.
- 글자 크기·터치 영역은 공통 디자인 가이드를 따릅니다. 공간이 부족하면 여백과 배치를 조정하고 세로 스크롤을 허용합니다.
- 동물 에셋에는 대비·선명도·입체감을 추가로 높이는 필터를 사용하지 않습니다. 부드러운 털 덩어리와 명암을 그대로 유지합니다.
- 캐릭터 PNG는 상하좌우 빈 투명 여백을 제거한 상태입니다. 카드 안의 간격과 동물 발밑 그림자는 CSS에서 별도로 조절합니다.

## 02A 적용 구분 — 빈 목장

참고: [02A-빈 목장.png](../mockups/farm/02A-빈%20목장.png)

- 공통 상단 아래에 크림색 환영 패널을 배치합니다. 배경의 특정 좌표에 고정하지 않고 콘텐츠 영역 안에서 가운데 정렬합니다.
- 패널은 둥근 사각형·얇은 밝은 테두리·공통 질감·부드러운 그림자로 만듭니다. 구름 모양 통이미지는 사용하지 않습니다.
- ‘보리야, 반가워!’ → ‘첫 책을 만들어 볼까요?’ → ‘새 책 만들기’ 버튼 순서로 세로 배치합니다.
- 인사 문구보다 질문 문구를 크게 표시하고, 버튼은 주변 문구와 충분한 간격을 둡니다.
- 모바일에서는 패널 폭과 안쪽 여백을 줄이고 문구 줄바꿈을 허용합니다. 동물·책 제목판·페이지 표시는 이 시안에 배치하지 않습니다.

## 02B 적용 구분 — 책이 있는 목장

참고: [02B-farm.png](../mockups/farm/02B-farm.png)

- 동물과 책 이름표 한 쌍을 같은 카드 래퍼로 묶습니다. 카드 자체에는 큰 배경판을 추가하지 않습니다.
- 태블릿은 3열×2행, 모바일은 2열×3행을 기준으로 배치합니다. 높이가 부족하면 세로 스크롤을 허용합니다.
- 동물 영역은 카드마다 같은 높이로 두고 아래쪽을 맞춥니다. 동물 이미지는 비율을 유지하여 표시하고, 양과 알파카의 보이는 크기는 각 래퍼 안에서 조정합니다.
- 카테고리는 작은 둥근 표식, 책 이름은 그 아래 넓은 제목판으로 표현합니다. 표식을 살짝 겹쳐 놓되 글자가 가려지지 않게 합니다.
- 책 이름이 길면 제목판의 높이를 늘리고 줄바꿈합니다. 그림 배경을 늘려 해결하지 않고 CSS 패딩과 높이로 조절합니다.
- 태블릿의 좌우 화살표는 동물 그리드 양옆에 배치하고, 그리드에는 화살표와 겹치지 않을 공간을 둡니다.
- 모바일에서는 화살표를 하단 페이지 점의 양옆으로 옮깁니다. 화살표 아이콘은 같은 SVG를 재사용하고 왼쪽만 회전합니다.
- 페이지는 숫자 대신 점으로 표현합니다. 현재 점은 올리브색으로 채우고 나머지는 크림색 바탕과 올리브색 테두리로 표시합니다.
- 비활성 화살표는 낮은 강조의 황갈색으로 표현합니다. 작은 점도 실제 터치 영역은 최소 48×48 CSS px를 확보합니다.

### 화면과 카드 배치

- **목장으로 → 화면 제목 → 일기·동화 카드 → 하단 안내** 순서로 배치합니다. 상단 제목은 ‘어떤 이야기를 들려줄까요?’입니다.
- 태블릿에서는 같은 너비의 카드 두 개를 나란히 놓습니다. `grid-template-columns: repeat(2, minmax(0, 1fr))`를 사용하고 카드 높이는 같은 행에서 맞춥니다.
- 카드 내부는 **카테고리 제목 → 삽화 영역 → 설명**의 세로 구조로 둡니다. 두 카드의 삽화 영역 높이와 설명 시작선을 맞춥니다.
- 일기 설명은 ‘오늘 있었던 일을 써요.’, 동화 설명은 ‘상상한 이야기를 써요.’를 사용합니다. 하단 안내는 ‘쓰고 싶은 이야기를 눌러 주세요.’입니다.
- 카드 전체가 하나의 터치 영역으로 보이게 합니다. 카드 안에 별도의 작은 선택 버튼을 추가하지 않습니다.
- 카드판과 줄 장식은 별도 레이어입니다. 카드 내부의 텍스트와 삽화는 정상 문서 흐름에 두고, 줄·구멍만 카드 기준으로 위치를 잡습니다.
- 줄의 긴 윗부분은 장식 래퍼에서 잘라 표시하되, 매듭과 아래 고리는 유지합니다. 줄 길이에 맞춰 카드를 고정 높이로 만들지 않습니다.

### 삽화 배치

- 카드마다 합본 PNG 한 장만 사용합니다. 캐릭터와 해·별·구름의 위치를 CSS로 각각 맞추지 않습니다.
- 두 카드의 삽화 래퍼에 같은 `aspect-ratio: 4 / 3`을 배치 시작값으로 적용합니다. 이 비율은 삽화 영역에만 적용하며 카드 전체 높이를 고정하지 않습니다.
- 이미지는 `display: block; width: 100%; height: 100%; object-fit: contain; object-position: center bottom;`으로 표시합니다. 파일마다 조금 다른 원본 비율을 그대로 유지합니다.
- `cover`나 가로·세로 강제 늘이기를 사용하지 않습니다. 양의 공책, 알파카의 귀·앞발, 해·별이 잘리지 않게 합니다.
- 두 PNG 모두 그림 바깥은 투명하며 상하좌우 빈 여백을 제거했습니다. 카드 안 여백은 래퍼의 padding·gap으로 설정합니다.
- 털에 대비·선명도 필터나 추가 질감을 씌우지 않습니다. 합본 그림을 회전·반전하지 않고 현재 시안의 동작과 방향을 유지합니다.
- 그림과 줄·질감 레이어는 `pointer-events: none`으로 두어 카드의 터치와 초점 표시를 방해하지 않게 합니다.

### 반응형·상태 스타일

- 제목·본문·버튼의 글자 크기는 공통 디자인 가이드를 따릅니다. 시안의 이미지 해상도를 CSS 크기로 환산해 화면 전체를 확대·축소하지 않습니다.
- 두 카드를 나란히 두었을 때 안내 글자가 지나치게 줄바꿈되면 한 열로 전환합니다. 모바일에서는 일기 → 동화 순서로 세로 배치하며 페이지 스크롤을 허용합니다.
- 카드의 고정 높이 대신 내용에 따른 높이 증가를 허용합니다. 두 카드가 한 행일 때만 같은 높이를 맞춥니다.
- 모바일에서도 합본 삽화의 비율을 유지해 줄입니다. 해·별·캐릭터의 상대 위치는 이미지 안에서 유지되며, 글자를 이미지 위의 고정 좌표에 두지 않습니다.
- 카드의 기본 테두리 두께를 유지한 채 `:focus-visible`은 바깥 outline으로 표시합니다. 눌림은 아래 그림자를 줄이는 정도로 표현해 카드나 주변 글자 위치가 크게 움직이지 않게 합니다.
- 돌아가기 버튼은 그림과 글자 길이에 맞춰 늘어날 수 있게 하고, 최소 터치 영역 48×48 CSS px를 확보합니다.

## 03B~03F 공통 CSS — 책 만들기 화면

### 에셋과 CSS

- 배경은 backgrounds/farm-meadow.png, 안내판과 버튼 질감은 textures/ui-paper-grain.png를 재사용합니다.

- 줄 장식은 backgrounds/hanging-rope-hole.png를 사용합니다. 밧줄·매듭·판에 들어가는 어두운 구멍·밝은 테두리가 한 이미지에 포함되어 있습니다. CSS 구멍이나 별도 고리를 중복해서 그리지 않습니다.
- 기존 hanging-rope.png는 현재 `design/archive/decorations/`에 있는 구형 참고 자료입니다. 03B~03F에는 현재 에셋인 `backgrounds/hanging-rope-hole.png`를 적용하며, 두 파일의 경로나 구멍 표현을 혼동하지 않습니다.

### 중앙 정렬과 모서리 캐릭터

- 안내판은 position: relative로 놓고, 내용은 한 열로 구성합니다. 기존 왼쪽 캐릭터 전용 열을 없애고 폼과 주제 목록이 판의 가용 너비를 사용하게 합니다.
- 카테고리·제목·주제 안내·주요 버튼은 안내판의 같은 수평 중심선에 맞춥니다. 입력란은 width: 100%와 max-width, margin-inline: auto를 사용합니다.
- ‘책 이름’ 라벨은 입력란 위에 두고 입력란의 왼쪽 시작점에 맞춥니다. 입력란 아래 오류 안내 공간을 확보합니다.
- 주요 버튼은 입력란보다 좁아도 되지만 margin-inline: auto로 중앙 정렬합니다. 상단 ‘뒤로’는 왼쪽 위치를 유지합니다.
- 얼굴 크기는 **양은 03B, 알파카는 03E를 기준으로 통일**합니다. 동일 캐릭터는 03B~03F에서 같은 크기 규칙을 사용합니다. 귀를 포함한 이미지 전체 폭만 같게 맞추기보다 실제 얼굴의 시각적 크기를 맞춥니다. 이 통일 규칙은 MD에만 기록하며 현재 목업의 얼굴 크기를 다시 변경하지 않습니다.
- 캐릭터는 안내판의 왼쪽 아래 모서리에 닿도록 배치하되 입력란·설명·버튼을 덮지 않습니다. 얼굴 이미지는 width와 height: auto로 비율을 유지하고 pointer-events: none을 적용합니다.
- 캐릭터를 놓기 위해 본문 왼쪽에 빈 열을 남기지 않습니다. 작은 화면에서 겹치면 캐릭터 크기와 바깥 돌출량을 줄이고 필요한 하단 공간을 확보합니다.

### 밧줄·구멍 배치

- 두 줄 장식은 안내판 기준으로 좌우 대칭 배치합니다. 이미지 하단의 구멍 중심을 판의 상단 안쪽에 맞춥니다.
- 원본 비율을 유지합니다. 긴 윗부분만 장식 래퍼에서 잘라 표시하고 매듭·구멍·테두리는 모두 남깁니다.
- 구멍 테두리는 크림색 판 위에 겹칩니다. 판 전체를 이미지로 만들거나 줄을 가로세로 따로 늘이지 않습니다.
- 줄과 캐릭터 레이어는 pointer-events: none으로 설정합니다. 입력란과 버튼의 초점 표시를 덮지 않습니다.

### 반응형

- 안내판은 max-width와 좌우 padding으로 너비를 정하고 높이는 내용에 따라 늘어납니다. 목업 픽셀 좌표로 화면을 고정하지 않습니다.
- 제목 32px·버튼 22px·안내 20px를 시작값으로 사용하고 공통 디자인 가이드를 따릅니다.
- 화면이 낮거나 키보드가 열리면 페이지 스크롤을 허용합니다. 입력란·커서가 잘리지 않게 하며 캐릭터와 줄 장식 공간을 먼저 줄입니다.
- 터치 영역은 최소 48×48 CSS px, 초점은 :focus-visible outline으로 표시합니다.

## 04 화면 공통 CSS — 일기·동화 글 목록

세 PNG 모두 바깥은 투명하고 상하좌우의 빈 투명 여백을 제거했습니다. 이미지 주위 간격은 CSS에서 줍니다. 책 바탕에는 목록 행·구분선이 없으므로 글자 위치가 바뀌어도 이미지와 어긋나지 않습니다.

### 공통 정렬과 크기

- 화면 구조는 **상단 왼쪽 목장으로 / 중앙 카테고리 → 책 이름 / 펼친 책 / 페이지네이션**입니다. 카테고리와 책 이름은 책 바깥 위쪽에 둡니다.
- 일기·동화가 동일한 화면 래퍼, 책 래퍼, toolbar, 목록 grid, 버튼 클래스를 재사용하게 합니다. 카테고리별 차이는 색·책 바탕·동물·안내 영역의 내용으로 한정합니다.
- 책 래퍼의 너비·높이·내부 여백은 두 카테고리에서 같습니다. PNG 원본 크기가 다르다는 이유로 동화책을 크게 만들지 않습니다.
- 책 내부 상단은 `grid-template-columns: repeat(2, minmax(0, 1fr))`를 기준으로 왼쪽 안내/보상, 오른쪽 버튼 2개를 둡니다. `align-items: center`로 세로 중심을 맞춥니다.
- 오른쪽 버튼은 동일한 높이와 폭의 2열 grid입니다. 새 일기 쓰기·새 장 쓰기의 글자 수가 달라도 버튼 크기를 유지합니다.
- 목록은 왼쪽 5개·오른쪽 5개입니다. 두 열 모두 같은 폭·행 높이·gap·padding을 사용합니다. 한 열의 마지막 항목만 들여쓰기하거나 폭을 줄이지 않습니다.
- 순서는 왼쪽 위→아래 5개, 오른쪽 위→아래 5개입니다. 두 개의 동일한 열 래퍼를 두거나, 5행 grid에 `grid-auto-flow: column`을 적용합니다. 시각적 순서와 키보드 탐색 순서가 일치하게 구성합니다.
- 행 내부는 내용과 오른쪽 화살표를 분리하고 내용에 `min-width: 0`, 아이콘에 `flex-shrink: 0`을 적용합니다. 행 전체가 터치 영역입니다.
- 날짜는 일반 굵기로 표시합니다. 동화의 장 번호와 첫 문장 미리보기도 일기 목록과 같은 글자 크기를 사용합니다. 긴 미리보기는 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`으로 처리하며 글자를 축소하지 않습니다.

### 공통 글자·터치 기준

1024×768 CSS px에서 확인할 시작값이며, 일기·동화에 동일한 토큰을 적용합니다. 생성 이미지의 픽셀을 CSS 값으로 그대로 옮기지 않습니다.

| 요소 | 글자 크기 / 굵기 |
| --- | --- |
| 책 이름 | 32px / 700 |
| 카테고리 표식 | 20px / 600 |
| 날짜·요일·장 번호·첫 문장 미리보기 | 24px / 400 |
| 새 글 쓰기·이어서 쓰기 버튼 | 22px / 600 |
| 안내 문구·이 책의 보상 | 20px / 500 |
| 목장으로 | 18px / 600 |
| 페이지 번호·보상 구간 숫자 | 20px / 600 |

- 버튼과 목록 행의 터치 영역은 최소 48px 높이, 아이콘 단독 버튼은 최소 48×48 CSS px로 둡니다. 인접 터치 영역 간 간격은 8px를 시작값으로 삼습니다.
- 보조 버튼도 일기·동화에서 같은 높이·글자 크기를 사용합니다. 색과 테두리로 주요 행동과 구분합니다.
- `:focus-visible`은 outline으로 표현해 주변 배치를 밀지 않게 합니다. 비활성 표시는 색상뿐 아니라 실제 disabled 상태와 연결합니다.

### 책 바탕과 반응형

- 책 그림은 내용과 분리된 장식 레이어입니다. 책 래퍼를 `position: relative`로 두고, 이미지에는 `position: absolute; inset: 0; width: 100%; height: 100%; pointer-events: none`을 적용합니다. 실제 toolbar와 목록은 정상 문서 흐름으로 배치합니다.
- 두 책 PNG는 약 2.13:1의 비슷한 비율입니다. 태블릿 공통 래퍼는 약 2.1:1을 시작값으로 삼고, 이 범위의 작은 차이는 장식 이미지에만 `object-fit: fill`을 적용해 외곽 크기를 맞춥니다. 글자나 버튼을 함께 늘이거나 화면 전체를 축소하지 않습니다.
- 콘텐츠의 최소 높이가 우선입니다. 긴 책 이름은 위쪽에서 줄바꿈하도록 하며 책 안 목록을 덮지 않게 합니다. 높이가 부족한 화면은 세로 스크롤을 허용합니다.
- 모바일에서 펼친 책을 좁고 길게 늘이는 방식은 피합니다. 2열을 유지하기 어려운 폭에서는 일기·동화 모두 같은 시점에 1열로 전환하고, 목록은 기존 순서를 유지합니다. 이때 펼친 책 장식은 감추고 CSS의 종이색·표지색 테두리·공통 질감으로 같은 내용 영역을 구성하는 것을 반응형 시작안으로 둡니다.
- 모바일에서도 글자 축소보다 toolbar 줄바꿈과 여백 조정을 먼저 적용합니다. 오른쪽 버튼 2개의 크기는 서로 같게 유지합니다.

### 모서리 캐릭터

- 기존 캐릭터 PNG만 사용합니다. 일기 양은 03B, 동화 알파카는 03E의 보이는 얼굴 크기를 기준으로 같은 크기 규칙을 재사용합니다.
- 얼굴은 책의 grid 밖 장식 레이어에 둡니다. 확대된 이미지의 몸통은 `overflow: hidden` 래퍼로 가리고 비율은 유지합니다.
- 캐릭터를 놓기 위해 책 왼쪽에 빈 열을 추가하거나 마지막 행을 옆으로 밀지 않습니다. 겹치면 캐릭터를 아래/바깥으로 옮기거나 노출 영역을 줄입니다.
- 장식에는 `pointer-events: none`을 적용하되, 이것만으로 글자가 가려지는 문제를 해결했다고 보지 않습니다. 목록 내용·버튼·페이지네이션이 실제로 모두 보이게 합니다.

### 페이지네이션 정렬

- 일기·동화 모두 페이지네이션 전체 묶음(이동 화살표와 페이지 번호)을 **화면 전체 너비의 수평 중앙**에 정렬합니다.
- 책의 한쪽 페이지나 캐릭터를 제외한 남은 공간을 기준으로 정렬하지 않습니다. 왼쪽 아래 캐릭터 때문에 페이지네이션을 오른쪽으로 밀지 않습니다.
- 화면 전체 너비를 사용하는 별도 래퍼에 `display: flex; justify-content: center;`를 적용합니다. 좌우 여백은 대칭으로 두고, 책 내부 열이나 캐릭터 레이아웃의 영향을 받지 않게 합니다.
- 반응형에서도 화면의 중심선을 유지합니다. 캐릭터와 겹치면 캐릭터의 위치·노출 범위 또는 세로 간격을 조정하며 페이지네이션의 수평 중심은 바꾸지 않습니다.
- 이 규칙은 수평 정렬 기준이며, 페이지네이션을 화면 하단에 고정하는 `position: fixed`를 의미하지 않습니다.

- 단일·겹화살표 아이콘은 버튼의 내부 중앙에 놓고 숫자 버튼과 같은 외곽 크기를 사용합니다. 현재 페이지는 올리브색, 나머지는 크림색으로 구분합니다.
- 목업 속 1~5를 고정 텍스트로 굽지 않습니다. 페이지 번호 묶음의 길이가 바뀌어도 전체 컨트롤 그룹의 수평 중심을 유지합니다.

- 일기책의 밝은 종이와 연두색 표지 바탕을 사용합니다. 상단의 ‘일기’ → 책 이름, 책 내부의 안내·버튼 위치는 공통 배치를 따릅니다.

## 04C 적용 구분 — 동화 기본 목록

- 일기와 동일한 책 래퍼·목록·버튼 크기에 아이보리 종이와 황갈색 표지 바탕을 적용합니다. 별도의 동화 전용 열 폭이나 큰 글자 규칙을 만들지 않습니다.
- 상단의 ‘동화’ → 책 이름 아래, toolbar 왼쪽에 보상 진행도를 두고 오른쪽에 ‘새 장 쓰기’·‘이어서 쓰기’를 둡니다.
- 보상 영역은 **이 책의 보상 + 가로 진행 막대 + 구간 위 선물 + 구간 아래 3·6·10**으로 구성합니다. ‘보상을 모은 장’, ‘다음 보상까지’, ‘3문장 이상 쓴 장’ 같은 설명을 추가하지 않습니다.
- 선물·숫자는 막대와 동일한 기준선을 사용합니다. 구간 위치는 최대 구간 10에 대한 비율로 맞추고, 마지막 선물이 영역 밖으로 잘리지 않도록 막대 양끝에 선물 반너비 이상의 여백을 둡니다.
- 수령 가능한 선물은 컬러 원본, 미달성 선물은 이미지에만 `filter: grayscale(1)`을 적용합니다. 텍스트와 막대 전체를 함께 회색으로 만들지 않습니다. 별도 회색 PNG는 필요하지 않습니다.
- 선물 그림은 약 32~40px 표시를 시작값으로 삼되 실제 버튼은 최소 48×48px로 확보합니다. 선물 자체를 버튼 내용으로 사용하고 별도의 ‘보상 받기’ 텍스트 버튼은 추가하지 않습니다. 키보드 초점과 접근 가능한 이름은 유지합니다.
- 구간 수령 완료 상태는 현재 기본 목업에 없으므로 회색을 임의로 수령 완료 의미에 재사용하지 않습니다. 미달성·수령 가능과 구별할 완료 스타일은 별도로 확인합니다.
- 진행도 높이 때문에 목록이나 오른쪽 버튼을 이동시키지 않습니다. 같은 toolbar 높이 안에서 선물과 숫자를 배치하며, 좁은 화면에서는 공통 반응형 규칙에 따라 toolbar를 줄바꿈합니다.
- 장 번호 영역의 너비를 일정하게 두어 1장과 10장 뒤 미리보기 시작선을 맞춥니다. 첫 문장 미리보기만 말줄임하고 장 번호와 화살표는 남깁니다.

## 04B 적용 구분 — 일기 빈 목록

## 04D 적용 구분 — 이야기 목록 조회 실패

- 책 내부에는 **목록 조회 실패 안내 문구와 ‘다시 불러오기’ 버튼만** 표시합니다. 안내는 실제 HTML 텍스트, 재시도는 공통 CSS 버튼으로 구성합니다.
- 글 목록 행·페이지네이션·‘새 일기 쓰기’·‘새 장 쓰기’·‘이어서 쓰기’는 조회 실패 상태에서 렌더링하지 않습니다. 숨긴 목록이나 toolbar의 빈 공간도 남기지 않습니다.
- 실패 안내와 재시도 버튼은 책의 전체 내용 영역을 기준으로 중앙 정렬합니다. 안내가 길면 줄바꿈과 세로 여백으로 대응하며, 옅은 복숭아색 바탕·둥근 모서리·짙은 글자를 사용합니다.
- 책 위의 카테고리 → 책 이름, ‘목장으로’와 책 바탕은 공통 배치를 유지합니다. 글자·버튼·얼굴 크기도 기본 목록과 같은 규칙을 적용합니다.
- 04D 목업의 목록과 새 글 쓰기·이어서 쓰기 버튼은 구현 시 제외합니다. 04B·04D는 목업 이미지를 수정하지 않고, 이미지와 다른 위 배치·표시 기준을 이 문서에서 우선 적용합니다.

### 공책과 상단 정렬

- 1024×768 CSS px의 가로 태블릿 시안이 기준입니다. 화면을 고정 크기로 확대·축소하지 않습니다.
- 공책의 오른쪽 면이 화면의 대부분을 차지하고 왼쪽에는 좁은 제본부만 보이게 합니다. 04 목록의 양쪽 페이지 배치를 복사하지 않습니다.
- 공책 래퍼는 `position: relative`로 두고 배경 이미지와 실제 내용을 별도 레이어로 구성합니다. 배경에는 `pointer-events: none`을 적용하고, 입력·버튼은 정상 문서 흐름으로 배치합니다.
- 공책 PNG의 원본 비율은 1261:1032입니다. 기본 상태는 이 비율을 출발점으로 삼되 내용 높이가 우선입니다. 내용이 길어졌을 때 글자와 입력을 배경에 맞춰 축소하지 않습니다.
- 공책 안쪽 여백은 제본부·종이 겹침을 피해서 잡습니다. 날짜, 안내 문구, 입력 밑줄, 확인 버튼은 공통 내용 래퍼의 좌우 기준선을 사용합니다.
- 상단은 **카테고리 왼쪽 / 날짜 오른쪽**의 한 행입니다. `display: flex; align-items: center; justify-content: space-between; gap: ...` 또는 동등한 grid를 사용합니다. 날짜 영역 자체도 날짜와 달력 아이콘의 세로 중심을 맞춥니다.
- 날짜 컨트롤의 오른쪽 끝과 입력 밑줄·확인 버튼의 오른쪽 끝을 맞춥니다. 카테고리와 날짜를 위아래로 쌓았던 이전 05A 배치는 사용하지 않습니다.
- 날짜는 실제 `input[type="date"]`와 연결하고 달력 UI는 브라우저 기본 기능을 사용합니다. 표시용 날짜·요일과 실제 선택값을 분리해 스타일링하더라도 날짜 선택의 클릭·키보드 초점 영역을 유지합니다.

### 입력과 버튼

- 상단 아래에 ‘한 문장씩 써요’, 입력 영역, 오른쪽 정렬의 ‘확인하기’를 배치합니다. 문장 입력을 큰 말풍선이나 별도 두꺼운 카드로 감싸지 않습니다.
- 입력 바탕은 종이가 보이도록 투명하게 두고 하단에 옅은 회색 선을 긋습니다. 날짜 뒤나 페이지 전체에 반복 줄을 넣지 않습니다.
- 빈 입력일 때 ‘여기에 오늘 있었던 일을 써봐요.’와 연필 아이콘을 보여줍니다. 내용이 입력되면 보조 문구와 연필은 사라집니다. 안내가 입력·클릭을 가리지 않게 하고, 실제 입력에는 별도의 접근 가능한 이름을 둡니다.
- 시안의 커서는 CSS 장식이나 이미지로 만들지 않고 실제 입력 caret을 사용합니다. `:focus-visible` 또는 `:focus-within`으로 현재 입력 영역을 구분합니다.
- 한 문장을 입력하는 기능과 화면에서 한 줄로 표시하는 것은 별개입니다. 긴 한 문장은 필요하면 줄바꿈할 수 있도록 입력 높이를 늘리고, 다른 요소를 덮지 않게 합니다.
- 05A의 비어 있는 입력 상태에서는 ‘확인하기’를 낮은 강조의 올리브 회색으로 표시합니다. 활성·눌림·초점 상태는 공통 버튼 스타일을 사용하며, 모든 상태에서 버튼의 크기를 유지합니다.

### 캐릭터와 그림자 없는 말풍선

- 양은 **왼쪽 아래 책 밖**에서 얼굴을 내밀게 배치합니다. 얼굴의 시각적 크기는 기존 03B 기준을 유지하고, 몸통은 전용 래퍼의 `overflow: hidden`으로 가립니다.
- 양을 공책 안의 내용 grid에 넣어 입력란을 밀지 않습니다. 입력·날짜·확인 버튼과 겹치면 캐릭터의 위치·노출 범위를 조절합니다.
- 말풍선 꼬리는 왼쪽 아래 양을 향합니다. 안내 문구는 ‘오늘 가장 기억에 남는 일을 떠올려 봐~’이며, 말풍선의 가운데 몸통 부분에 실제 텍스트로 넣습니다. 꼬리와 둥근 가장자리는 텍스트 영역에서 제외합니다.
- **말풍선 PNG에는 그림자가 없습니다.** 목업의 부드러운 외부 그림자를 표현할 경우에만 이미지 레이어에 CSS `filter: drop-shadow(...)`를 적용해 조절합니다. 직사각형 테두리에 생기는 `box-shadow`를 말풍선에 그대로 적용하거나 PNG에 그림자를 다시 합성하지 않습니다.
- 말풍선은 원본 비율을 유지하고 텍스트는 별도 레이어로 배치합니다. 이 이미지는 05A의 짧은 안내용입니다. 긴 교정 설명을 넣기 위해 억지로 세로로 늘이거나 글자를 줄이지 않고, 06의 설명 영역은 해당 시안에서 따로 조정합니다.
